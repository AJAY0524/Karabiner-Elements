# 繁體中文（zh-Hant）用語與表記規則

以台灣 macOS 介面用語為準，畫面間統一下列譯名。

## 用語

| 英語                         | 繁體中文             |
| ---------------------------- | -------------------- |
| Profile                      | 設定檔               |
| Complex Modifications        | 複雜修改             |
| Simple Modifications         | 簡單修改             |
| Sticky modifier keys         | 黏滯修飾鍵           |
| Modifier keys                | 修飾鍵               |
| EventViewer                  | 事件檢視器           |
| Multitouch Extension         | 多點觸控延伸功能     |
| Driver Extensions            | 驅動程式延伸功能     |
| Login Items & Extensions     | 登入項目與延伸功能   |
| Privacy & Security           | 隱私權與安全性       |
| Accessibility                | 輔助使用             |
| Input Monitoring             | 輸入監控             |
| Capture                      | 擷取                 |
| Permission                   | 權限                 |
| Background services          | 背景服務             |
| Quit / Restart               | 結束／重新啟動       |
| Log                          | 記錄                 |
| Expert                       | 專家模式             |
| Menu bar                     | 選單列               |
| Scroll                       | 捲動                 |
| Keyboard shortcut            | 快速鍵               |
| Keyboard layout              | 鍵盤配置             |
| Eject (key)                  | 退出鍵               |

## 表記規則

- 中文與英數字之間加半形空格，例如 `Karabiner-Elements 設定`、`X 軸`。
- 引號使用「」，巢狀引號使用『』。
- 標點使用全形（，。：（）），但設定鍵、檔名與 `{count}` 等 placeholder 不變。
- Apple App 名稱沿用台灣 macOS 官方名稱（Finder、Dock、Spotlight、指揮中心、巧控鍵盤、Touch ID）。
